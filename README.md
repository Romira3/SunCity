# Solaris Energy — демонстраційний сайт

## Запуск
Відкрийте `index.html` у браузері або завантажте всі файли на хостинг.

## Структура
- `index.html` — розмітка сайту
- `style.css` — адаптивні стилі
- `script.js` — меню, dropdown, калькулятор і демонстраційна форма
- `assets/` — локальні SVG-зображення

## Важливо
Форма не відправляє дані на сервер. Для реального сайту підключіть backend, CRM або сервіс обробки заявок.
